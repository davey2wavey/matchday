# Matchday
Standings and weekly fixtures. Data pulled live from ESPN's public JSON in the browser; no server, no keys.

- `/` — My Week: starred teams across sports, one week grid
- `tonight/` — everything on in the next 24 hours, Pacific
- `soccer/` — Premier League, Champions League, La Liga
- `nba/` — NBA
- `shared.js`, `shared.css` — stars, time, fetch helpers

Stars and view settings live in the browser (localStorage).
